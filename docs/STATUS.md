## Areas tracked but not yet in the registry

XSAPI (profile/achievements/sessions — stub/fail-soft only, live is 0%),
XGameUI / TCUI, XDisplay, XSystem, XStore, Game Chat, AcpHal / XMA,
shader lifting (DXIL route), unified memory (`MEM_GRAPHICS`).
XGameSave / XGameSaveFiles / XPackage are in the registry now (phases 2–3);
`XGameSaveCreateUpdate`-family, `XGameSaveFilesGetFolderWithUi*`, and
`XPackageEnumeratePackages` / `XPackageMountWithUi*` are implemented.
Software ray tracing is in the registry now (`ScSoftwareRT_*`, see
docs/SOFTWARE-RT.md) — compute-shader DXR replacement, verified on the
5700 XT. Optimization components are in the layer now as flat `ScOpt_*`
entry points (see docs/OPTIMIZATION.md): PSO/root-signature cache,
de-tiled texture cache (CPU + GPU, VRAM budget + LRU), mesh-shader
fallback, async compute, descriptor heap pool, DirectStorage (overlapped
I/O — desktop runtime absent) + BCPack (ZLIB CPU decode, BCPack
E_NOTIMPL), shader precompilation cache, frame batching. Still open: the
COM wrapper that routes a real title's `ID3D12Device` /
`ID3D12GraphicsCommandList` calls (PSO creation, mesh dispatch,
DirectStorage queues, RT calls) to those components, hardware DXR
passthrough for RT-capable adapters, and the exact Xbox tiled-texture
bit layout (the Morton swizzle is the documented shape; hardware
exactness is unverified until real Xbox tiled data lands).
